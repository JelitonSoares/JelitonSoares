## 🕹 About:
I have been passionate about technology since I was young, when I used to hack the neighbor's Wi-Fi because I didn't have internet. Due to my situation, I had to start working early in a different field, but recently I've been transitioning into the area I've always liked. Currently, I develop applications using Java and Spring Framework, but I've also worked with other technologies such as JavaScript, HTML, CSS, and Python. In my free time, I enjoy gaming, watching live streams and videos that expand my knowledge. I'm an astronomy and financial management enthusiast. Feel free to explore my projects; I'd love to chat.
